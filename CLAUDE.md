# Media workflow

Read `docs/recording-previews.md` before recording VPX previews. Fetch available
community media with `tools/fetch_media.py`, then use `tools/record_previews.py`
for missing videos. Use the installed launcher configuration; the repository
copy may be stale. Preserve existing media unless replacement is requested.
Do not commit VPX tables, ROMs, PuP packs, generated frames, or generated videos.
